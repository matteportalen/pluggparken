Vad vill du räkna?

Världens stjärnor: klara alla banor och bossen = ⭐, alla med minst ⭐⭐ = ⭐⭐, alla med ⭐⭐⭐ = ⭐⭐⭐.

Dator: ← → springer, ↑ hoppar (två gånger = dubbelhopp), mellanslag förtrollar fiender med trollstaven (eller hoppa på dem). Surfplatta och mobil: knapparna på skärmen. Hoppa med huvudet i rätt svar för att öppna porten! I Havsriket simmar du: håll ↑ (eller ⤒) för att simma uppåt.
